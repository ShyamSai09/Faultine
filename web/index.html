    Does the memory actually connect these incidents?
    
    
    
      Every incident sits in a hand-labelled cluster of failures that share a root cause. For each one
      we ask Hindsight to recall the failure mode and check which of its true siblings come back.
      Only recall is involved: no generation, no model call, just BM25, the entity
      graph, temporal filters and a cross-encoder ranking locally.
